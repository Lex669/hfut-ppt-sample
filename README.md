# hfut-ppt-sample
合工大ppt模板，可用于组会汇报、开题答辩、毕业答辩，base on周师兄的答辩ppt。

## 引言

经历了一年科研，从刚开始的对ppt无所谓，只要能讲懂即可，到现在认为ppt反而是讲懂的最重要的部分，老师同学并没有持续的高精力去听汇报人答辩人所讲的，更多的是阅读ppt再适当的倾听汇报人的陈述，因此有开始学习制作高质量ppt的必要了。



制作ppt是一门学问，在科研邻域中ppt主要讲究精简、高效，而非花里胡哨，有助于更高效、清晰传达自己的学术观点。



而本项目所制作的模板主要聚焦于框架，并非是排版的模板，本人也在持续学习优秀的ppt样例，比如已毕业的周师兄的答辩ppt，考虑到保密就不放出来了，将这些优秀的ppt进行总结，提取其中的排版方法论，之后会将该模板进行更新。



## one more thing

并不是说把ppt做好就可以做好汇报答辩工作，学术ppt的作用是帮助演讲者想观众清晰、准确、高效的传递信息，也就是位于演讲者与观众之间的工具。汇报的好坏取决于**内容的充实程度和演讲者的思维条理**，这需要规范性学术训练和扎实的研究工作支持。
